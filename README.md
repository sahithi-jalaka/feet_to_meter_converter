
# Feet to Meter Converter using Python Tkinter

## 📌 Project Description
The Feet to Meter Converter is a simple Python GUI application developed using the Tkinter library. It converts measurements from feet to meters using a standard conversion formula.

## ✨ Features
- Simple and user-friendly graphical interface.
- Accepts measurements in feet.
- Converts feet into meters instantly.
- Displays results up to four decimal places.
- Handles invalid input with an error message.

## 🛠️ Technologies Used
- Python 3
- Tkinter

## 📐 Conversion Formula

**1 foot = 0.3048 meters**

Meters = Feet × 0.3048

**Example:**

Input: 10 feet

Output: 3.0480 meters
